# EvensonCalder Homebrew Tap

Official Homebrew Tap for [EvensonCalder](https://github.com/EvensonCalder) packages.

## Usage

```bash
brew tap EvensonCalder/tap
brew install --cask mygopia
```

## Available Casks

| Cask | Description |
| :--- | :--- |
| [`mygopia`](https://github.com/EvensonCalder/mygopia) | Fast, native cross-platform desktop client for Kopia backup and instant cross-snapshot search |
